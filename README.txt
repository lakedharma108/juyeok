GitHub Pages 배포 방법
1. GitHub에서 Public 저장소를 새로 만듭니다.
2. 이 ZIP 파일의 압축을 풀고 안의 파일들을 저장소 최상위에 업로드합니다. (ZIP 파일 자체를 올리지 마세요.)
3. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.
4. 잠시 후 생성된 주소에서 앱을 실행할 수 있습니다.

index.html은 원본 APK에서 추출한 웹 앱이며, manifest 및 아이콘과 서비스워커를 추가했습니다.
