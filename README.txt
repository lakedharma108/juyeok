관 · 주역 1.4 — 점괘 결과에서 십익 주석 바로 읽기

업데이트 내용
점괘 결과 → 십익 주석: 본괘·지괘의 단전·상전과 건곤의 문언전을 바로 읽습니다.
64괘 사전 → 십익 · 十翼 → 편 선택 → 장 또는 괘 선택.
단전 상·하, 상전 상·하, 계사전 상·하, 문언전, 설괘전, 서괘전, 잡괘전의 원문·번역·해설을 읽습니다.
64괘 상세 화면에서 해당 괘의 단전·상전·문언전으로 이동할 수 있습니다.
십익 전체 검색, 글자 크기 조절, 마지막 읽은 항목 이어 읽기를 지원합니다.

기존 GitHub Pages 업데이트
1. ZIP을 압축 해제합니다. ZIP 파일 자체를 올리지 마세요.
2. 기존 저장소의 같은 위치에 index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png를 덮어씁니다.
3. 변경 사항을 커밋하고 Pages 배포 완료 후 기존 주소를 새로고침합니다.
4. 설치한 웹앱은 온라인에서 다시 열고, 이전 화면이면 앱을 완전히 닫았다 다시 엽니다.
같은 주소를 유지하고 브라우저 데이터를 삭제하지 않으면 기존 점괘 기록을 유지할 수 있습니다.

원문은 공개 고전이며, 한국어 번역과 해설은 앱을 위해 작성한 초역입니다. 전문 역주자의 감수를 거치지 않았습니다. 각 항목에서 원문 출처를 확인할 수 있습니다.
